## 📁 Estrutura do Projeto

```
hangman-game/
├── .git/                 # Controle de versão Git
├── README.md             # Documentação principal do projeto
├── admin.php             # Área administrativa para cadastro
├── game.php              # Página principal do jogo
├── index.php             # Página inicial/menu principal
├── ranking.php           # Página de ranking dos jogadores
├── backend/              # Scripts PHP do servidor
│   ├── add_word.php      # Processar cadastro de palavras
│   ├── catch_word.php    # API para buscar palavras aleatórias
│   ├── config.php        # Configuração e conexão do banco
│   └── save_score.php    # API para salvar pontuações
├── css/                  # Estilos e design
│   └── style.css         # Arquivo principal de estilos CSS
├── docs/                 # Documentação do projeto
│   ├── proposal.md       # Proposta e especificações
│   └── structure.md      # Este arquivo - estrutura do projeto
├── img/                  # Imagens e recursos visuais
│   └── background.gif    # GIF de background animado
├── js/                   # Scripts JavaScript
│   ├── menu.js           # Controle e lógica do menu
│   └── script.js         # Lógica principal e mecânicas do jogo
└── others/               # Arquivos auxiliares e recursos
    └── xampp.png         # Imagem do XAMPP para documentação
```
